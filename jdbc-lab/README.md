# JDBC Lab - Student Database

This project is part of the Enterprise Application course. It demonstrates how to connect Java to a MySQL database using JDBC.

## Technologies

* Java
* MySQL
* JDBC
* Maven

## Features

* Connect Java to MySQL
* Create a database and student table
* Insert student records
* Display student records
* Update student information
* Delete student records
* Calculate the average grade

## Database

* Database name: `StudentsDB`
* Table name: `students`
* Columns: `id`, `firstname`, `lastname`, `grade`

## How to Run

1. Install Java and MySQL.
2. Configure the MySQL connection in the Java code.
3. Add the MySQL Connector/J dependency to `pom.xml`.
4. Run the main Java class from IntelliJ IDEA.
